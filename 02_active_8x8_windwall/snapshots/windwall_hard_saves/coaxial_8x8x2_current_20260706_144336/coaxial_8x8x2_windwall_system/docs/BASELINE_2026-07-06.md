## Naming Decision

Use wind-pixel pair numbers plus explicit layer labels:

```text
P01-P64 = coaxial wind-pixel pairs
F01-F64 = front-layer motors
B01-B64 = back-layer motors
```

The model also supports signed display aliases such as `+01` and `-01`, but
those should stay out of primary command files, logs, and hardware protocols.
