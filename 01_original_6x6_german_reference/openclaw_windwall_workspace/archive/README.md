# Windwall Archive

This archive captures the Pi, Pico, motor, Kitronik, comms, and firmware work done before the project pivoted back to a strict German-wall-first workflow.

Intent:
- preserve all prior exploration
- avoid losing hardware findings, dead ends, and working notes
- provide a clean stopping point before restarting from a 100% German 36-motor baseline

Contents in this archive should be treated as historical reference, not current implementation authority.
