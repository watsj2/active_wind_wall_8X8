# Windwall Local Reference

This folder is for local cached notes and references for the 8x8 Windwall project so work can continue with limited bandwidth.

## Upstream reference

## Local intent
- Preserve useful architecture from the 6x6 upstream.
- Adapt it to the 8x8 / 64-motor / 8-Pico layout.
- Use the Kitronik 3151 Simply Robotics Motor Driver Board for Raspberry Pi Pico as the controller-board baseline.
- Prefer doing downloads and repo sync while good connectivity is available.
